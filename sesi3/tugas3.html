GitHub Assignment Guide (Task #4)
How to publish your assignment layout to GitHub:
  1. Create a free account at github.com if you haven't yet.
  2. Click the "New Repository" button in your dashboard.
  3. Give it a name (e.g. aji-waluyo-bootstrap-portfolio) and make sure it is set to **Public**.
  4. Click **Create Repository**.
  5. Open your command prompt or terminal in the folder containing this index.html file and execute: 
    git init
git add index.html
git commit -m "feat: complete Bootstrap portfolio homework"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/aji-waluyo-bootstrap-portfolio.git
git push -u origin main
  6. Provide your homework repository URL link to your instructor to complete task 4 successfully!
Make sure to replace YOUR_USERNAME in step 5 with your actual registered GitHub profile username!
